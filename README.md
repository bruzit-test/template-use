# Template

[![Last commit](https://img.shields.io/github/last-commit/bruzit-test/template-use)](https://github.com/bruzit-test/template-use/commits)

Standardized repository scaffold for BruzIT projects. Pre-configured with semantic-release, license boilerplate, README structure, and initial v0.0.0 tag.

## Features

- [`LICENSE`](LICENSE)
- [`README.md`](README.md)

## Installation and Setup

Create a repository from this template.

## Usage

Recommended [`README.md`](README.md) structure:

- Description
- Features
- Installation and Configuration
- Usage
- Support
- Contributing
  - Development
  - Testing
  - Operations
- Copyright and Licensing
